# 오행 로또 · 재물운 달력

사주(명리) 기반 로또 번호 추천 · 재물운 달력 · 구매/당첨 기록 · 용지 QR 스캔 개인 웹앱.

- 재물운 월달력(발복 점수·목돈일), 사주 기반 5줄 번호 추천(패턴 선택 반영)
- 구매/당첨 기록, 용지 QR 스캔(구매기록·즉석 당첨확인), 운좋은날·꿈 기록
- 손익 아닌 누적 수익 + 내 신호(사주·직감·꿈) 적중 분석
- 기본은 이 기기(브라우저) 로컬 저장, 로그인 시 클라우드(Supabase) 동기화

정적 단일 페이지(`index.html`) + 오행연 엔진(`engine.browser.js`) + QR 디코더(`jsQR.min.js`).

> 번호·날짜 추천은 사주 참고용이며 당첨을 보장하지 않습니다.
